# HARDLE Unlimited 🟩

An unofficial infinite version of [Hardle](https://hardle.org) — a harder twist on Wordle where you only get the **count** of correct letters, not which ones they are.

Built so my friends and I could play more than once a day!

## 🎮 How to Play

1. Guess a **5-letter word**
2. After each guess, you'll see:
   - 🟩 How many letters are in the **correct position**
   - 🟧 How many letters are in the word but in the **wrong position**
3. Click on submitted letters to track your deductions:
   - **Gray** → Not in word
   - **Orange** → Wrong position
   - **Green** → Correct position
4. Solve it in **10 guesses** or less!

## 🧠 What Makes Hardle Different?

Unlike Wordle, you don't know **which** letters are correct — only **how many**. This turns the game from pattern matching into a **combinatorial logic puzzle**, closer to Mastermind than Wordle.

## ✨ Features

- 🔄 **Unlimited puzzles** — no waiting for tomorrow
- 🎨 **Tile color cycling** — track your deductions by clicking letters
- 📊 **Statistics** — track games played, win rate, streaks, and guess distribution
- ↺ **Row reset** — clear your color annotations and rethink
- ❓ **How to play** — built-in help modal
- 📱 **Works on mobile** — play anywhere
- 🔍 **SEO optimized** — so others can find it too
